# 🧱 Cimentar México — Pon tu primera piedra

Sitio web ciudadano e independiente que traduce la participación cívica en **acciones concretas**, guiadas por cinco principios: razón, consciencia individual, consciencia colectiva, empatía y crecimiento general.

Inspirado en el espíritu de plataformas ciudadanas como Construir México, pero con identidad propia: no pedimos registros, pedimos **obras** — microacciones verificables que cualquier persona puede hacer hoy.

## Contenido del sitio
- **Cinco principios para cimentar** — el marco filosófico.
- **Guía del ciudadano constructor** — 5 pasos con acciones concretas y una "acción mínima de hoy" en cada uno.
- **🎲 Dado cívico** — generador de microacciones diarias (menos de 30 minutos).
- **🧱 Mi primera piedra** — checklist de compromiso personal, compartible por WhatsApp.

## Estructura
```
index.html    # Página única
styles.css    # Estilos (paleta tierra/arena/dorado)
app.js        # Dado cívico, checklist y botones de WhatsApp
```

## Configuración (1 minuto)
1. En `app.js`, línea 2: cambia `WHATSAPP_NUMERO` por tu número con código de país (ej. `5215512345678`).
2. Listo. Los botones de WhatsApp apuntarán a tu número.

## Publicación gratuita (GitHub Pages)
```bash
git init
git add .
git commit -m "Cimentar México: primera piedra"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/cimentar-mexico.git
git push -u origin main
```
Luego en GitHub: **Settings → Pages → Source: main branch → Save**.
Tu sitio quedará en `https://TU_USUARIO.github.io/cimentar-mexico/`
